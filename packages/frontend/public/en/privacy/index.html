Controller

Hosting

This site is served as a static website via GitHub Pages (GitHub, Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA). When you open it, GitHub processes technically necessary connection data such as IP address, timestamp, requested file and user agent in server log files. The legal basis is Art. 6(1)(f) GDPR (legitimate interest in operating the site). See the GitHub privacy statement.

No cookies, no tracking

The site sets no cookies and embeds no analytics or advertising services. Your chosen language and colour scheme are stored locally in your browser's localStorage only and are never transmitted. The selected month and filters are kept in the address bar so that views can be shared.

Data retrieval

The listed additions are collected in advance server-side and loaded as static JSON files from this same domain. Visiting the page does not contact any streaming service.

No embedded third-party content

The site loads no images, fonts or scripts from external servers. Simply viewing the page does not create any connection to third parties.

External links

The title cards link directly to the respective service (Netflix, Disney+, Prime Video). Data is only transmitted to those services once you click such a link; their own privacy policies apply then.

Your rights

You have the right to access, rectification, erasure, restriction of processing, data portability and objection (Art. 15–21 GDPR), as well as the right to lodge a complaint with a supervisory authority. Please use the contact address above.
